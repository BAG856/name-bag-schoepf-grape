## Kostenlose Veröffentlichung mit GitHub Pages
GitHub Pages bietet Hosting für statische Websites in einem öffentlichen Repository mit GitHub Free. Die veröffentlichte Website ist öffentlich erreichbar.

1. Ein Konto auf https://github.com anlegen oder anmelden.
2. Ein neues **Public** Repository erstellen, z. B. `bag-schoepf-grape`.
3. Die drei HTML-Dateien (`index.html`, `impressum.html`, `datenschutz.html`) in die oberste Ebene des Repositorys hochladen.
4. Im Repository zu **Settings → Pages** gehen.
5. Bei **Build and deployment** als Quelle **Deploy from a branch** auswählen.
6. Branch `main` und Ordner `/(root)` wählen, speichern.
7. Warten, bis GitHub Pages die Veröffentlichung abgeschlossen hat; danach zeigt die Pages-Einstellung die Website-Adresse an. Sie hat typischerweise die Form `https://BENUTZERNAME.github.io/bag-schoepf-grape/`.
8. Website auf Smartphone und Computer prüfen.

Offizielle Anleitung: https://docs.github.com/de/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Eigene Domain
Eine Domain wie `hausarzt-franzburg.de` ist normalerweise separat zu registrieren und nicht kostenlos. Ob ein Wunschname verfügbar ist, muss bei einem Domain-Registrar geprüft werden. GitHub Pages kann anschließend eine benutzerdefinierte Domain verwenden; dazu werden die Domain in den Pages-Einstellungen und passende DNS-Einträge beim Registrar konfiguriert.
Offizielle Anleitung: https://docs.github.com/de/pages/configuring-a-custom-domain-for-your-github-pages-site

## Vor Veröffentlichung unbedingt erledigen
- Telefonnummer und Fax telefonisch bestätigen.
- Sprechzeiten gemeinsam bestätigen oder den Vorschlag ersetzen.
- E-Mail-Adresse ergänzen, falls vorhanden.
- Impressum um Kammer, Berufsrecht, weitere Pflichtangaben ergänzen und rechtlich prüfen.
- Datenschutzhinweise an tatsächlichen Hosting-Anbieter und dessen Datenverarbeitung anpassen.
- Domainverfügbarkeit prüfen; eine Domain wird nicht durch diese Dateien registriert.
- Keine Patientendaten, Zugangsdaten oder vertraulichen Dokumente in ein öffentliches Repository stellen.
